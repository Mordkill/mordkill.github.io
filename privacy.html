Privacy policy: Claude health

Last updated: 17 October 2026

Claude health is a personal, single-user tool built and used by Jonathan M. Nobody else can sign in to it.

What data it accesses

With the user's consent through Google sign-in, it has read-only access to the following Google Health data: activity and fitness (workouts, steps, active minutes, calories), health metrics (such as heart rate), sleep, and nutrition logs.

How the data is used

The data is read on demand by a small program on the user's own computer and passed to the user's AI assistant, so it can answer the user's questions about their own training, activity and nutrition. It is not used for advertising, profiling or any other purpose.

Storage and sharing

Sign-in tokens are stored only on the user's own computer. Health data is not stored on any server run by this app, and it is not sold or shared with any third party, apart from the AI assistant the user uses to analyse their own data. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
